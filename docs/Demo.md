Ramp easy works by creating a parallel version of your original source code. It automatically adds hooks before each line of code, capturing detailed information about your program’s execution."

These hooks send real-time data about every line executed to a Message queue. The server collects and consolidates this information into a comprehensive recording of the entire program run.
